## Quick Start

### Prerequisites
- Node.js 18+
- npm or yarn

### Installation
```bash
git clone https://github.com/bakery-street-project/store.cd store
cd store
npm install
# or: yarn install
```

### Usage
```bash
# Start development
npm start

# Run tests
npm test

# Build for production
npm run build
```
